One line of software error copy that tells the user the brutal truth about a failed login — and makes them laugh: the password was correct, the database was not. It names the real failure in plain words, says what to do next (try again in about five minutes), and would survive being pasted into a real product's error dialog.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (set `OUTPUT_PATH` to write elsewhere for a local run). The program self-checks the gate before writing: 1–200 characters, a single non-blank line.
